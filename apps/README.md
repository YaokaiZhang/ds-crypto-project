# Applications

- [Frontend](frontend/README.md): install, run and build the Vue application.
- [Backend](backend/README.md): configure providers, start analysis workers and enable the live feed.
- [Model deployment](../deploy/README.md): reproduce or deploy the five-model API.

Run the API and workers with the same server configuration. The browser calls
the backend; provider credentials and model-service keys stay on the server.
